# biblioteca-de-babel

Library Management System.

## Requirements

* Node.js 22 or higher
* Docker
* Git

## Installation

Clone the repository:

```bash
git clone https://github.com/JulianBodo/biblioteca-de-babel.git
cd biblioteca-de-babel
```

Install dependencies:

```bash
npm install
```

Start PostgreSQL:

```bash
docker compose up -d
```

Start the development server:

```bash
npm run dev
```
